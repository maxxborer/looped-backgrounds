# Looped backgrounds

Пять процедурных анимированных фонов на HTML, CSS и JavaScript. Каждый цикл длится 12 секунд. Галерея: `index.html`.

| Сцена | Стиль |
| --- | --- |
| Ultraviolet | Фиолетовые звёзды и мерцающая пыль |
| Blue starfall | Поток чистых голубых неоновых контуров |
| Heartbeat | Парящие розовые сердца с непрерывными линиями |
| Nacre | Перламутровые ленты на фоне цвета морской глубины |
| Orrery | Янтарные орбитальные скульптуры |

## Воспроизведение

HTML-файлы в `backgrounds/` открываются прямо с диска. Общие JS/CSS должны оставаться рядом. Для сервера: `npm start`, затем http://127.0.0.1:4173.

В OBS для MP4 используйте «Источник медиа» с включённым повтором. Для HTML используйте источник «Браузер»: локальный файл, 2560×1440, 60 кадров/с. Режим уменьшения движения в системе останавливает живую анимацию.

## Видео

Каждый фон поставляется в двух вариантах: SDR H.264 для широкой совместимости и HDR10 HEVC Main10 для HDR-экранов. Оба: 2560×1440, 60 кадров/с, 12 секунд, 720 кадров, без звука. HDR требует совместимого проигрывателя и включённого HDR-режима; универсального HDR-файла для любого устройства не существует. На обычном экране используйте SDR.

## Разработка

Node.js 20+, FFmpeg и FFprobe в PATH:

```sh
npm ci
npx playwright install chromium
npm run render
npm run verify
```

Переменные окружения: `CHROMIUM_PATH`, `PLAYWRIGHT_PACKAGE_ROOT`, `FFMPEG_PATH`, `FFPROBE_PATH`. Видео хранятся в `exports/` и исключены из Git.

`npm run render -- --preview` обновляет только JPG. Для одной сцены: `npm run render -- --scene=04-nacre`. Пробный экспорт: добавьте `--frames=12`; короткие образцы сохраняются в `output/`, основные видео не затрагиваются. `npm run verify -- --source-only` проверяет HTML без чтения MP4.

## Цвет и HDR

SDR-файлы: H.264, 8 бит, Rec.709, limited range. HDR-файлы имеют суффикс `-hdr10`: HEVC Main10, 10 бит, Rec.2020, ST 2084 PQ, limited range, тег `hvc1`, статические HDR10-метаданные. Обе версии содержат faststart для начала воспроизведения до полной загрузки.

HDR — отдельная цветовая обработка процедурного sRGB-рисунка: линеаризация sRGB, расширение яркости с мягким акцентом на светах, пересчёт первичных цветов в Rec.2020 и кодирование абсолютной яркости PQ. Номинальная яркость базового белого — 203 нит, предельная яркость усиленных светов — 600 нит. В метаданных указаны консервативные верхние пределы MaxCLL 600 и MaxFALL 200 нит, а не результаты измерения дисплея. Проверка преобразования цвета: `node scripts/verify-color.mjs`.

Источник Canvas 2D имеет 8-битный sRGB-растр; HDR-обработка не превращает его в нативный высокоточный HDR-рендер. Передача кадров в кодировщик использует PNG без JPEG-потерь, цветовые вычисления выполняются в float, финальное квантование — с дизерингом. Простого изменения цветовых меток без пересчёта пикселей нет.

Совместимость с любым существующим устройством не гарантируется. Для обычного экрана выбирайте SDR. Для HDR нужны соответствующий экран, режим вывода и проигрыватель с HEVC Main10; предпросмотр в браузере по умолчанию использует SDR и возвращается к нему при ошибке HDR-декодирования. Проверка файлов не заменяет оценку на физическом HDR-дисплее.

## Геометрия и цикл

У трёх сцен с отдельными фигурами размещение учитывает размеры элементов, поворот и покачивание. Общий перенос по вертикали сохраняет расстояния. Элементы, проходящие границу кадра, рисуются также на противоположном краю. В орбитальной сцене пересечения линий являются частью конструкции.

Время каждого кадра задаётся как `frame / 60`. Все движения периодичны за 12 секунд. Кадр на 12-й секунде не добавляется в конец файла: это первый кадр следующего повтора. При изменении пропорций окна используется центральное кадрирование без растягивания фигур.

Проверка анализирует зазоры на всех 720 шагах, пиксельное совпадение 0 и 12 секунд, плавность перехода через границу, наличие движения, декодируемое число кадров в обеих версиях, цветовые теги и HDR10-метаданные. Дополнительно проверяются мобильная галерея, изображения и остановка движения во всех пяти сценах. Результаты: `exports/verification.json` и `exports/color-verification.json`.

`node scripts/measure-hdr.mjs` дополнительно декодирует четыре момента каждого HDR-ролика и измеряет яркость в нитах. Отчёт `exports/hdr-luminance.json` содержит выборочные измерения сигнала, а не проверку физического экрана.
